无屏手环

无屏手环

Pulse Band、Pulse Band Lite 的接入入口。下表只列出本产品要用的接口，字段、取值和示例以链接页为准。

SDK 接入、连接与快速配置

注册、蓝牙、绑定、状态回调以链接页为准。Full 用内置蓝牙库；Lite 自管蓝牙后再标记连接。Full 与 Lite 二选一，见 IDO SDK 集成说明。

步骤 接口
注册 IDOSDK sdk.bridge.setupBridge。Android 先 sdk.init。Full 再 蓝牙库 sdk.ble.addBleDelegate。实现 IDOBridgeDelegate
扫描、连接 Full：蓝牙库 startScan、connect、autoConnect。Lite：自管连接成功后 桥接 markConnectedDevice；断开 markDisconnectedDevice
是否已绑定 IDOBridgeDelegate checkDeviceBindState。由 App 根据本地存储的与设备绑定关系返回：false 走首次绑定；true 走快速配置。App 须自行持久化绑定关系
首次绑定 绑定/解绑 sdk.cmd.bind。绑定中 isBinding 为 true 时不要切换设备
快速配置 IDOStatusNotification：fastSyncStarting 开始，fastSyncCompleted 完成，fastSyncFailed 失败后由业务再触发。已绑定回连时 SDK 自动走快速配置（功能表、设备信息、三级版本、时间）
业务指令 Cmds.xxx().send、sdk.syncData、sdk.dataExchange 等。须在 fastSyncCompleted 之后。快速配置中下发返回 错误码 -4

时序：首次绑定

App                              SDK / 设备
 |                                |
 |-- setupBridge / init --------->|
 |-- addBleDelegate（Full） ----->|
 |                                |
 |-- startScan ------------------>|
 |<- 设备列表 --------------------|
 |-- connect -------------------->|
 |<- 连接成功 --------------------|
 |                                |
 |-- checkDeviceBindState ------->|   返回 false
 |-- sdk.cmd.bind --------------->|
 |<- onDeviceInfo / onFuncTable --|
 |<- 绑定成功 --------------------|
 |                                |
 |<- fastSyncStarting ------------|
 |   （此时勿发 Cmds / 同步 / 交换）|
 |<- fastSyncCompleted -----------|
 |                                |
 |-- 业务指令（设置/查询/同步） -->|

时序：已绑定回连

App                              SDK / 设备
 |                                |
 |-- connect / autoConnect ------>|   Full
 |   或 markConnectedDevice ----->|   Lite，isBinded = true
 |<- 连接成功 --------------------|
 |                                |
 |-- checkDeviceBindState ------->|   返回 true
 |                                |
 |<- fastSyncStarting ------------|
 |   （此时勿发 Cmds / 同步 / 交换）|
 |<- fastSyncCompleted -----------|
 |                                |
 |-- 业务指令 ------------------>|
 |   如 getDeviceStatusInfo、     |
 |   健康同步、数据交换            |

时序：业务指令时机

连接成功
  ├─ 未绑定 → bind 成功 → 快速配置完成 → 业务指令
  └─ 已绑定 → 快速配置完成 → 业务指令

快速配置进行中：不下发业务指令（errorCode -4）
快速配置失败：按 fastSyncFailed 再触发后再发业务指令

运动

运动由 App 发起，实时数据走 数据交换。当次小结见 获取 V3 运动小结。已结束的运动记录走 同步多运动合集。

蓝牙断开后，手环自行保持本次运动，不随 App 断连结束。App 回连后要与手环的运动状态、当次累计数据一致，使用下面两个接口，缺一不可：

能力 接口
手环是否仍在运动中 获取设备状态 getDeviceStatusInfo，getType 传 1。回连后先查。hasSportStartType 为 true 时看 sportStartType：0 未运动，1 App 发起，2 设备发起，3 运动自识别。为 0 时本次运动已结束，不必拉快照
运动中全量快照 多运动全量快照 dataExchange.getActivityExchangeFullSnapshot。手环断线期间自行累计的当次数据。确认仍在运动中后拉取，用返回的 JSON 对齐 App 运动中界面，再继续数据交换
开始、暂停、恢复、结束 数据交换 appExec。App 发起的运动中，设备判定未在运动时：listenDeviceNotification type 127（无 parameter）；确认结束后再 appExec 结束
运动类型 设置运动排序 setSport100Sort。查询时 operate 传 1，设备支持的运动类型在回复 items 里，每项 type 见 IDOSportType
运动自识别 设置运动模式识别开关 setActivitySwitch、获取运动模式自动识别开关 getActivitySwitch。仅活动开关 autoIdentifyGeneralActivity，见 IDOActivitySwitchModel。识别结束后：listenDeviceNotification type 126，parameter 为运动开始本地时间戳（秒）；再 同步多运动合集

手势怎么配

无屏手环手势是「总开关 + 三选一」。同一时间只能开通话、拍照、音乐中的一种。默认总开关关闭；开启时默认选遥控拍照。仅支持手腕佩戴。字段与接口见 IDOGestureControlModel。

gestureControlOnOff（总开关）
        │
        ├─ 关 → 所有手势不生效
        │
        └─ 开 → 三选一（仅其中一个 functionSwitch = 1）
                │
                ├─ functionType = 1  控制通话
                │       ├─ 接听电话  ← 绑定一种 gestureType
                │       └─ 挂断电话  ← 绑定另一种 gestureType（与接听互斥）
                │
                ├─ functionType = 2  控制拍照
                │       └─ 遥控拍照  ← 绑定一种 gestureType
                │
                └─ functionType = 3  控制音乐
                        └─ 下一曲    ← 绑定一种 gestureType

产品默认手势（可按设备支持项调整）：

模式 子功能 手势
控制通话 接听电话 手臂水平旋转两次
控制通话 挂断电话 先手臂水平旋转两次，再手臂垂直旋转两次
控制拍照 遥控拍照 手臂水平旋转两次
控制音乐 下一曲 手臂水平旋转两次

gestureType 取值（查询支持项后再下发）：

值 含义
1 手掌翻转 90° 两次
2 弹两下
3 手臂水平旋转 90° 两次
4 手臂垂直旋转 90° 两次（仅通话挂断可选）

同一功能下，各子功能所选手势互斥。例如接听已选「手臂水平旋转两次」时，挂断只能选其它手势。

  • iOS：手势只支持来电时接听或拒接，不支持通话中用手势挂断。
  • 遥控拍照：手机系统相机已打开，且蓝牙已连接；快门走 HID，不走协议指令。
  • 音乐下一曲：蓝牙已连接。
